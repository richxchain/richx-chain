<h1 align="center">RichX Coin (RICHX)</h1>

RichX Coin is the native coin of RichX Chain. It pays for every transaction on the chain.

| | |
|---|---|
| Symbol | RICHX |
| Type | native coin (no contract) |
| Decimals | 18 |
| Supply | 1,000,000,000, fixed at the start of the chain |
| Website | https://richx.finance |

A native coin has no mint function, so the supply cannot be increased.
